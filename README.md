# 指ナビ タイピング

次に押すキーと「**どの指で押すか**」を画面のキーボードと手の図で教えてくれる、ブラインドタッチ練習サイトです。

- 画面のキーボードが指ごとに色分け、次のキーが光る
- 手の図で、使う指がハイライト(Shift が必要なときは反対の手の小指も)
- 間違えると「いま押したのは〇〇指、正しくは△△指」と表示
- レッスン: ホーム段 → G/H → 上段 → 下段 → 英単語 → ローマ字(ひらがな付き) → 数字 → 英文 → 苦手キー
- ヒント量を4段階で減らせる(全部 → キー文字を隠す → ミス時だけ → なし)
- JIS / US 配列対応(Chrome/Edge では自動判定)
- 速度・正確率・苦手キー・自己ベストはブラウザ内に保存

`index.html` 1ファイルだけで動きます。ダブルクリックで開くか GitHub Pages で公開してください。
