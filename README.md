# 指ナビ タイピング

次に押すキーと「**どの指で押すか**」を画面のキーボードと手の図で教えてくれる、ブラインドタッチ練習サイトです。
**https://asaka6.github.io/yubi-navi-typing/**

- 最初に**ホームポジションの解説**(置き方 → 指の担当 → 打ち方のルール → 置いてみる)
- 練習は**意味のある文章**で(日本語の文をローマ字で打つ)
  - 短い文 → ふつうの文 → 長めの文(読点あり) → 英語の文 → 数字・記号入りの文 → 苦手キーが多い文
- キーボードに**透かしの手**を重ねて表示。使う指が光り、押すキーまで指先が伸びる(Shift は反対の手の小指も)
- 間違えると「いま押したのは〇〇指、正しくは△△指」と表示
- ヒントを4段階で減らせる(全部 → キー文字を隠す → ミス時だけ → なし)
- **スクロールなしで1画面に収まる**(画面の大きさに合わせてキーボードの大きさが変わる)
- JIS / US 配列対応、速度・正確率・自己ベストはブラウザ内に保存

`index.html` 1ファイルだけで動きます。
